# Техническое задание на разработку фронтенд части календаря для записи к врачу.

## Описание:

- Разработать визуальную часть (виджет) календаря, для записи к врачу. Функционал календаря представляет из себя возможность выбора одной даты и времени либо ввода даты в поле ввода.

## Технические требования:

- Календарь разработать используя библиотеку React.
- Данные, со свободными датами возможными для выбора и времени, приходят с backend в JSON формате.
- Первый шаг: пользователь выбирает дату из свободных начиная от текущей.
- Второй шаг: после выбора даты, пользователю открывается возможность выбора свободного временного промежутка из выпадающего списка.
- Третий шаг: после выбора времени приема у пользователя становится активной кнопка подтверждения выбора. Эта же кнопка является submit кнопкой, для отправки формы на backend.
- Числа идущие до текущего дня, не активны для выбора.
- Текущий день и последующие возможны для выбора, если на выбранный день ничего не занято.

## Визуальные требования:

- Визуально пользователь должен видеть все числа, текущего месяца.
- Черная рамка с закругленными углами.
- Белый фон.
- У каждой даты рамка серого цвета.
- При наведении на дату, ее фон закрашивается полупрозрачным синим цветом.
- Выбранная дата, закрашивается синим цветом.
- Выпадающий список c временем, имеет черную рамку с закруглениями и тень.
- Наведение и выбор временного промежутка закрашиваются теми же цветами, что и дата.
- Кнопка подтверждения выбора: в неактивном состоянии имеет серый цвет, в активном, синий, при наведении, темно-синий.
